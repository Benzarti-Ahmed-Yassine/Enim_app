# **App Name**: TempAlert

## Core Features:

- Real-time Temperature Display: Display the instantaneous temperature reading.
- Daily Data Logging: Record and store temperature readings throughout the day in the database.
- Dashboard Visualization: Present a dashboard view of the day's temperature data, allowing users to easily grasp trends and fluctuations.
- Historical Data Access: Provide access to historical temperature data, allowing users to review past trends and patterns.
- Threshold Configuration: Allow users to configure a desired temperature threshold.
- Email Alert System: Send an email alert via Nodemailer when the temperature exceeds the user-configured threshold.

## Style Guidelines:

- Primary color: Deep blue (#2962FF) to convey reliability and precision.
- Background color: Light grayish-blue (#E0E9FF) to provide a calming, readable backdrop.
- Accent color: Vibrant orange (#FF7729) for alerts and interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern look.
- Use clear and intuitive icons to represent temperature, settings, and alerts.
- A clean and responsive layout, optimized for displaying real-time data and historical trends effectively.
- Smooth transitions and subtle animations to enhance user engagement without distraction.
