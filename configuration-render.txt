=== RÉCAPITULATIF POUR LE DÉPLOIEMENT (VERSION FINALE) ===

Pour que l'envoi d'e-mails fonctionne, vous DEVEZ utiliser un "Mot de passe d'application" Google.

COMMENT OBTENIR VOTRE CODE DE 16 CARACTÈRES ?
--------------------------------------------
1. Connectez-vous à votre compte Google (Gmail).
2. Allez dans "Gérer votre compte Google" > Onglet "Sécurité".
3. Activez la "Validation en deux étapes" (obligatoire).
4. Une fois activée, recherchez la barre de recherche en haut et tapez "Mots de passe d'application".
5. Donnez-lui un nom (ex: "ENIM TempAlert").
6. Copiez le code de 16 caractères qui s'affiche (il n'a pas d'espaces, ex: "abcd efgh ijkl mnop").
7. Collez ce code dans la variable EMAIL_PASS de votre hébergeur (Netlify ou Render).
